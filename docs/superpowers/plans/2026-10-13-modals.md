# Modals and Pop-ups Revamp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (the user chose Native execution). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restyle the three dialogs (card on desktop, bottom sheet under 640px), the actions menu, select panels and toasts to the warm-neutral look, without changing behavior or wording.

**Architecture:** Four slices, one commit each. Class changes happen inside the shared shadcn primitives (`ui/dialog.tsx`, `ui/dropdown-menu.tsx`, `ui/select.tsx`) using Tailwind hex utilities, because these render in portals outside `.app-shell`. A temporary guard test strips every `className` value and `*Classes` constant from each touched file and compares a SHA-256 against baselines taken from commit `27939bc`; files that gain markup are re-baselined once, after a diff review.

**Tech Stack:** React 19, Radix Dialog/DropdownMenu/Select, Tailwind 4 + tw-animate-css, sonner 2, Vitest (node env).

**Spec:** [2026-10-13-modals-design.md](../specs/2026-10-13-modals-design.md)

## Global Constraints

- No new branch. Work on `page-revamp`; temporary tests are deleted before the final cleanup commit; commits use explicit paths; nothing is pushed.
- Colours are Tailwind hex utilities: ink `#111110` / `#f4f4f2`; bg `#ffffff` / `#0b0b0c`; surface `#f6f5f2` / `#151517`; muted `#5c5b56` / `#a3a29c`; hairline `#e5e3dc` / `white/12`; strong hairline `#cfcdc5` / `white/25`; focus ring `#1f3f8f` / `#8fb0ff`; red `#b3261e` / `#ff8a80`.
- Sheet under `sm` (640px): `max-h-[90dvh]`, `pb-[max(1.25rem,env(safe-area-inset-bottom))]`. Card from `sm` up.
- Behavior untouched: `open`/`onOpenChange` wiring, Logout cannot close while `loggingOut`, all handlers, all texts from `DocLabels`, toast calls.
- Do not edit `ui/button.tsx`, `ui/tooltip.tsx` (already ink), `ui/input.tsx` or `ui/label.tsx`.

## Review Focus

- The sheet and the card share one `DialogContent`: the `sm:` overrides must fully cancel the sheet positioning (no half-pinned card at 640-700px) - user click-check at 360, 639, 640 and 1280px.
- Escape, scrim click, Tab trap and focus return still work (Radix) - user click-check.
- The Logout dialog stays open during "Logging out..." - guard (handler text unchanged) + click-check.
- Sonner `classNames` conflicts: `error` must win over the default ink background - one class per type, no overlapping `bg-*`.
- Dark mode contrast of every pair (Task 0 script).
